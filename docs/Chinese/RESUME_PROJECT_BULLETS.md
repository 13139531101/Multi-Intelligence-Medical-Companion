## 一、完整版（投 AI 应用 / Agent 方向岗位）

**PHA · 个人健康多智能体系统** ｜ 独立开发 ｜ `<起止时间，填你自己的>` ｜ 开源仓库：`<链接>`

> 一句话：**用四套协议分层把一个"会聊天的大模型"做成了"能干活、能操作界面、有度量"的产品** ——
> 4 个领域智能体 + 70 个 MCP 工具 + 13 个容器，从架构、后端、前端到部署独立完成，316 次提交 / 48 个迭代阶段。

- **协议分层架构**：按调用边界把系统切成四层 —— MCP（智能体↔工具，**70 个工具**）、
  A2A（智能体↔智能体，4 个领域智能体互调）、AG-UI（智能体↔界面，**28 个标准事件**全部通过
  `@ag-ui/core@0.0.57` 官方 schema 校验）、ANP（跨组织身份，Ed25519 + DID:WBA 签名验签）。
- **有度量的 RAG 管线**：多跳检索 + 知识图谱扩展 + 重排（DashScope `gte-rerank-v2`），
  自建评测脚本做 **4 组消融**（single/multi × vector/rerank，18 条自然语言用例），
  得出**重排是多跳检索的必需项**（不加重排 MRR 0.6667 → 加重排 **0.95**，+0.283）；
  并保留负结果（重排在简单查询上 MRR 1.0 → 0.9333）作为后续优化依据。
- **让 AI 真正操作界面**：从后端工具打通到前端组件注册表，用户说"只看检查的"页面会真的跳转并切 tab；
  按**幂等性**把 12 个动作拆成两条通道 —— 幂等状态走 AG-UI 标准 `STATE_DELTA`（RFC 6902 JSON Patch），
  瞬态副作用保留自定义事件，解决"状态重放无害、动作重放出事"的问题。
- **工程化与可观测**：LangGraph 显式状态机 + HITL 中断/恢复 + `AsyncPostgresSaver` 持久化；
  连接池单例化（**省 3 秒冷启动**）；语义缓存、多模型自动降级、限流、工具调用硬上限、
  写操作二次确认（WriteGuard）+ 审计；Docker Compose 13 容器 + K8s manifests 一键起。

## 四、写简历时的四条纪律

1. **数字必须能对上**。上面每个数字都能在仓库里找到 —— **别再加自己没验证过的数字**。
   一个被戳穿的假数字，会毁掉整份简历的可信度。
2. **技术关键词要覆盖 JD**。对方 JD 写"LangGraph / RAG / 多智能体 / MCP"，你就得让这几个词出现。
   简历初筛很多是关键词匹配，**这不是作弊，是让对方有机会看到你**。
3. **不要写"精通"**。写"独立设计并实现"、"落地"、"修过线上故障" —— 这些是可验证的。
4. **一页纸**。项目占 3-5 行，剩下的留给技能和经历。**没人会读第二页。**
