# 魔塔社区嵌入模型下载指南

## 概述

本指南详细介绍如何从魔塔社区（ModelScope）下载嵌入模型，特别是解决 `sentence-transformers/all-MiniLM-L6-v2` 等模型在国内网络环境下的下载问题。<mcreference link="https://blog.csdn.net/sinat_17584329/article/details/146967744" index="5">5</mcreference>

## 为什么选择魔塔社区？

### 优势对比

| 特性 | Hugging Face | 魔塔社区 |

| 网络访问 | 经常被墙，下载缓慢 | 国内服务器，下载稳定 |
| 中文支持 | 英文为主 | 中文友好，文档齐全 |
| 模型丰富度 | 全球最全 | 主流模型齐全，国产模型优势 |
| 使用门槛 | 较高 | 低门槛，适合快速上手 |

## 方法一：使用 ModelScope CLI 下载

### 1. 安装 ModelScope

```bash
pip install modelscope
```

### 2. 下载完整模型

```bash
# 下载 all-MiniLM-L6-v2 模型到本地目录
modelscope download --model 'sentence-transformers/all-MiniLM-L6-v2' --local_dir './models'
```

### 3. 下载单个文件

```bash
# 下载指定文件到当前路径下的 dir 目录
modelscope download --model sentence-transformers/all-MiniLM-L6-v2 README.md --local_dir ./dir
```

```python
from modelscope.hub.snapshot_download import snapshot_download

# 下载模型到指定目录
```

### 2. 修改代码适配 ModelScope

#### 原始 Hugging Face 代码：

```python
from sentence_transformers import SentenceTransformer

model = SentenceTransformer('all-MiniLM-L6-v2')
```

```python
import os
os.environ['MODELSCOPE_CACHE'] = './models'

from modelscope.utils.constant import Tasks

# 加载本地模型
embedding_model = pipeline(
    task=Tasks.sentence_embedding,
    model='./models/sentence-transformers/all-MiniLM-L6-v2',
    model_revision='v1.0.0'
)

# 生成嵌入向量
texts = ["Hello World", "How are you?"]
results = embedding_model(inputs={'source_sentence': texts})
embeddings = [result['embedding'] for result in results]
```

## 集成到现有项目

### 修改 embedding_service.py

在您的项目中，可以这样修改嵌入服务：

```python
import os
import logging
from typing import List, Optional
from modelscope.pipelines import pipeline
from modelscope.utils.constant import Tasks

class EmbeddingService:
    def __init__(self, model_name: str = 'all-MiniLM-L6-v2'):
        self.logger = logging.getLogger(__name__)
        self.model_name = model_name
        self.model = None
        self.embedding_dim = 384
        
        # 设置模型缓存路径
        os.environ['MODELSCOPE_CACHE'] = './models'
        
        self._load_model()
    
    def _load_model(self):
        """加载嵌入模型"""
        try:
            # 尝试加载本地 ModelScope 模型
            model_path = f'./models/sentence-transformers/{self.model_name}'
            if os.path.exists(model_path):
                self.model = pipeline(
                    task=Tasks.sentence_embedding,
                    model=model_path,
                    device='cpu'
                )
                self.logger.info(f"成功加载本地模型: {model_path}")
            else:
                # 如果本地不存在，尝试在线下载
                self.model = pipeline(
                    task=Tasks.sentence_embedding,
                    model=f'sentence-transformers/{self.model_name}'
                )
                self.logger.info(f"成功加载在线模型: {self.model_name}")
                
        except Exception as e:
            self.logger.warning(f"ModelScope 模型加载失败: {e}，使用备用方案")
            self.model = None
    
    def encode(self, texts: List[str]) -> List[List[float]]:
        """编码文本为嵌入向量"""
        if self.model is None:
            # 使用备用的简单嵌入方法
            return [self._simple_embedding(text) for text in texts]
        
        try:
            results = self.model(inputs={'source_sentence': texts})
            return [result['embedding'].tolist() for result in results]
        except Exception as e:
            self.logger.error(f"嵌入编码失败: {e}")
            return [self._simple_embedding(text) for text in texts]
    
    def _simple_embedding(self, text: str) -> List[float]:
        """简单的备用嵌入方法"""
        import hashlib
        
        # 清理文本
        text = text.strip().lower()
        
        # 生成384维向量
        embedding = []
        for i in range(384):
            hash_input = f"{text}_{i}".encode('utf-8')
            hash_value = hashlib.md5(hash_input).hexdigest()
            float_value = int(hash_value[:8], 16) / (16**8)
            embedding.append((float_value - 0.5) * 2)
        
        return embedding
```

## 验证下载和使用

### 测试脚本

```python
def test_modelscope_embedding():
    """测试 ModelScope 嵌入模型"""
    import os
    os.environ['MODELSCOPE_CACHE'] = './models'
    
    from modelscope.pipelines import pipeline
    from modelscope.utils.constant import Tasks
    import numpy as np
    
    try:
        # 加载模型
        model = pipeline(
            task=Tasks.sentence_embedding,
            model='./models/sentence-transformers/all-MiniLM-L6-v2'
        )
        
        # 测试文本
        texts = ["这是一个测试句子", "This is a test sentence"]
        
        # 生成嵌入
        results = model(inputs={'source_sentence': texts})
        embeddings = [result['embedding'] for result in results]
        
        # 验证结果
        print(f"嵌入维度: {len(embeddings[0])}")
        print(f"嵌入数量: {len(embeddings)}")
        
        # 计算相似度
        similarity = np.dot(embeddings[0], embeddings[1])
        print(f"文本相似度: {similarity:.4f}")
        
        print("✅ ModelScope 嵌入模型测试成功！")
        return True
        
    except Exception as e:
        print(f"❌ 测试失败: {e}")
        return False

if __name__ == "__main__":
    test_modelscope_embedding()
```

## 常见问题解决

### 1. 下载速度慢

```bash
# 设置镜像源
pip install modelscope -i https://pypi.tuna.tsinghua.edu.cn/simple/
```

### 2. 权限问题

```bash
# 确保目录权限
chmod -R 755 ./models
```

### 3. 磁盘空间不足

```bash
# 检查模型大小（all-MiniLM-L6-v2 约 90MB）
du -sh ./models
```

### 4. 网络连接问题

如果仍然无法下载，可以：

1. 使用代理：
```bash
export https_proxy=http://your-proxy:port
modelscope download --model 'sentence-transformers/all-MiniLM-L6-v2' --local_dir './models'
```

2. 手动下载：访问 [ModelScope 官网](https://modelscope.cn/models/sentence-transformers/all-MiniLM-L6-v2) 手动下载文件
