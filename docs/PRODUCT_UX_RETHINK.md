# 首页重构: Today First

> 日期: 2026-07-25
> 设计原则: 第一屏回答"今天我要做什么"

---

## 旧版问题 (Dashboard)

- 第一屏看到的是 "17 个档案 / 0 报告 / 0/8 服药 / 0/100 评分" — 历史数据堆叠
- 用户进来不知道从哪开始
- 视觉重心分散: 4 个智能体卡 + 4 个概览数字 + 7 天趋势 + 最近对话 + 健康评分条

## 新版 (Today First)

### 顶部 Tab (不放底部, 走统一)
- 今天 (默认)
- 档案
- 聊天
- 我

### 今天页布局

```
┌─────────────────────────────────┐
│ 你好, 张大爷          [🔔] [头像]│  ← 头部: 人话 + 头像
├─────────────────────────────────┤
│ 今天 · 7月25日 周五              │  ← 时间锚
│                                 │
│ ┌─────────────────────────────┐ │
│ │ ⏰ 该吃药了                  │ │
│ │ 早上 8:00                   │ │  ← Hero 整块大
│ │ 硝苯地平 30mg · 钙片        │ │
│ │ [ 吃了 ]    [ 跳过 ]        │ │
│ └─────────────────────────────┘ │
│                                 │
│ ─── 今天的清单 ───              │
│ ✓ 早上 (8:02)                  │  ← 已做划掉
│ □ 中午 12:30                   │
│ □ 晚上 8:00                    │
│                                 │
│ ▼ 看看明天                     │
│ ▼ 上周 (5 天按时吃药)          │
└─────────────────────────────────┘
```

### 没了的东西 (挪走)

- 健康评分 0/100 → 挪到 "我"
- 7 天柱图 → 挪到 "档案"
- 4 个智能体入口 → 挪到 "聊天"
- 最近对话 → 挪到 "聊天"

### 情绪价值怎么藏

- "今天吃了 2 次, 漏 0 次" — 数字说话, 不评判
- "上周 5 天按时" — 用人话, 不用百分比
- 漏了不带红字, 自然灰
