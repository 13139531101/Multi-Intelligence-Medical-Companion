feat(stage48-22 v23): 新首页 TodayDashboard — Today First 设计

背景: 用户反馈 "一眼看不到重点, 我们想表达什么"
     之前体检表 23 项修的都是表层 bug, 核心 UX 流程没动

诊断 (用户 + 我一起走):
  1. 信息堆一起找不到 → 第一眼看不到重点
  2. AI 助手不知何时出现 → FAB 永远杵那
  3. 操作反馈不及时 → 做完没反应
  用户决议: 第一屏应该回答 "今天我要做什么"
  设计原则:
    - 今天 + 明天 + 上周 (主次分清)
    - 大字 + 人话 + 数字 (不评判)
    - 按钮不放底部 (用户确认: 网页端底部跟手机端不一致, 走统一)
    - 情绪价值藏在数字里, 不哄小孩

实现 (1 commit):
  新文件 frontend/multiagent_front/src/pages/TodayDashboard.jsx:
    - 顶部: "早上好, 张大爷" + 通知 + 头像 (人话, 不是"用户名")
    - 日期: "今天 · 7月25日 周五" (时间锚)
    - Hero (大块, 醒目): "该吃药了" + 药名剂量 + 吃了/跳过 两按钮
      没药时: "今天的药都吃完啦" / "今天没安排吃药, 去添加"
    - 今天清单: 早/中/晚 分段, ✓ 已吃, □ 待吃, ✗ 跳过 (灰色)
    - 数字总结: "今天吃了 2 次, 还有 1 次没吃" (数字, 不哄)
    - 明天 (折叠): 默认收起
    - 上周 (折叠): "上周 5 天按时吃药" (人话, 不百分比)
    - 别的功能 (在内容下方, 不在底部): 我的报告 / 吃药管理 / 问小助手

  App.jsx:
    - 注册 /v2/today -> TodayDashboard (ProtectedRoute)
    - 默认路由 / 和 * 重定向到 /v2/today (不再到 dashboard)
    - 老 /v2/dashboard 保留 (给开发者用)

  docs/PRODUCT_UX_RETHINK.md:
    - 写下设计决策 + 旧版问题 + 新版布局 ASCII
    - 未来 UX 重做的存档, 不在 HEALTH_RECORDS_UX_AUDIT 里混

接收路径:
  - 用户登录后 -> /v2/today (新首页)
  - 浏览器打开 http://localhost:5174/v2/today
