## 数据流说明

### 正向流程（用户请求处理）
1. **用户输入** → React前端 → FastAPI网关
2. **智能体路由** → 根据内容分发到相应A2A智能体
3. **工具调用** → A2A智能体通过MCP协议调用工具服务
4. **数据处理** → 工具服务访问数据库和外部服务
5. **结果返回** → 经过智能体处理返回给用户

### 反向流程（主动通知）
1. **事件触发** → 定时任务或数据变化
2. **工具执行** → MCP工具检测到需要通知的事件
3. **智能体处理** → 相关A2A智能体生成通知内容
4. **推送服务** → 通过WebSocket/SSE推送到前端
5. **用户接收** → 前端展示提醒和通知

## 关键交互模式

### 1. 同步工具调用
```
A2A智能体 --[MCP请求]--> MCP工具 --[执行]--> 数据服务 --[结果]--> A2A智能体
```

### 2. 异步事件处理
```
数据变化 --[事件]--> MCP工具 --[通知]--> A2A智能体 --[处理]--> 前端推送
```

### 3. 智能体协同
```
智能体A --[消息]--> 智能体B --[协作]--> 共同完成复杂任务
```

## 技术特性

1. **模块化架构**：每个智能体和工具都可以独立开发部署
2. **协议标准化**：基于MCP协议的工具调用接口
3. **异步高性能**：全链路异步处理，支持高并发
4. **扩展性强**：易于添加新的智能体和工具服务
5. **安全可靠**：端到端加密和权限控制
