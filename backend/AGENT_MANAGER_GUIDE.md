# 智能体管理器使用指南

## 概述

个人智能健康助手的智能体管理器已经过全面优化，现在支持配置文件管理、自动监控、健康检查等高级功能。

## 主要改进

### 1. 路径处理优化
- ✅ 修复了"目录不存在"的问题
- ✅ 支持从任意目录执行启动脚本
- ✅ 使用绝对路径确保可靠性

### 2. 配置文件管理
- ✅ 支持JSON配置文件 (`agent_config.json`)
- ✅ 可自定义智能体设置和系统参数
- ✅ 支持运行时配置保存和加载

### 3. 增强的监控功能
- ✅ 自动进程监控和重启
- ✅ 健康检查机制
- ✅ 详细的日志记录
- ✅ 端口占用检测

### 4. 改进的用户体验
- ✅ 交互式状态查看
- ✅ 优雅的启动/停止管理
- ✅ 实时运行时间统计
- ✅ 彩色状态提示

## 使用方法

### 基本启动
```bash
# 使用默认配置启动
python start_all_agents.py

# 使用自定义配置文件
python start_all_agents.py --config custom_config.json
```

### 交互式命令
启动后可使用以下命令：
- `s` + Enter: 查看智能体状态
- `q` + Enter: 退出程序
- `h` 或 `help`: 显示帮助信息

### 配置文件结构

```json
{
  "agents": [
    {
      "name": "智能体名称",
      "folder": "智能体目录",
      "port": 端口号,
      "description": "功能描述",
      "category": "health_core|utility",
      "auto_restart": true,
      "health_check_enabled": true
    }
  ],
  "settings": {
    "startup_delay": 2,
    "health_check_delay": 10,
    "health_check_timeout": 2,
    "health_check_retries": 5,
    "process_monitor_interval": 5,
    "restart_delay": 2,
    "shutdown_timeout": 5,
    "log_retention_days": 7
  }
}
```

## 日志管理

- 日志文件位置: `logs/agent_manager_YYYYMMDD_HHMMSS.log`
- 支持文件和控制台双重输出
- 自动记录启动、停止、错误等事件
- 可配置日志保留天数

## 故障排除

### 常见问题

1. **端口被占用**
   - 检查端口占用情况
   - 修改配置文件中的端口设置

2. **智能体启动失败**
   - 检查 `.env` 文件是否存在
   - 确认API密钥配置正确
   - 查看日志文件获取详细错误信息

3. **健康检查失败**
   - 等待更长时间让服务完全启动
   - 检查智能体是否支持 `/ping` 端点
   - 调整健康检查超时设置

### 环境要求

- Python 3.8+
- 所需依赖包（见 `requirements.txt`）
- 各智能体目录下的 `main.py` 和 `.env` 文件

2. **配置调优**
