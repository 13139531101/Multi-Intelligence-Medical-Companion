# 个人智能健康助手 - 部署使用说明

## 项目概述

本项目包含四个核心智能体，每个智能体都配置了专门的MCP工具，可以与Claude Desktop集成使用。

### 智能体列表

1. **健康档案管理员 (HealthRecordsManager)** - 端口 8001
   - OCR文档识别
   - 数据提取和结构化
   - 健康档案存储管理

2. **健康顾问 (HealthAdvisor)** - 端口 8002
   - 医疗知识查询
   - AI智能诊断分析（集成讯飞医疗大模型）

3. **用药提醒助手 (MedicationReminder)** - 端口 8003
   - 用药提醒管理
   - 智能通知服务

4. **就诊摘要生成 (VisitSummaryGenerator)** - 端口 8004
   - 医疗文档解析
   - AI健康分析

## 环境配置

### 1. Python环境

```bash
# 安装Python依赖
pip install -r requirements.txt
```

### 2. 环境变量配置

项目已配置使用讯飞医疗大模型和阿里云OCR服务。请确保 `.env` 文件中的配置正确：

```env
# 讯飞星火大模型配置
LLM_PROVIDER=spark
SPARK_APP_ID=your_app_id
SPARK_API_KEY=your_api_key
SPARK_API_SECRET=your_api_secret
SPARK_API_VERSION=v3.5

# 阿里云OCR配置
OCR_PROVIDER=aliyun
ALIYUN_ACCESS_KEY_ID=your_access_key_id
ALIYUN_ACCESS_KEY_SECRET=your_access_key_secret
```

## MCP配置

### Claude Desktop配置

每个智能体都有独立的 `mcp_config.json` 文件，可以直接复制到Claude Desktop的配置中。

**Windows配置文件位置：**
```
C:\Users\YourUsername\AppData\Roaming\Claude\claude_desktop_config.json
```

**配置示例（健康顾问）：**
```json
{
  "mcpServers": {
    "KnowledgeTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\HealthAdvisor\\mcpserver\\knowledge_tool.py"]
    },
    "DiagnosisTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\HealthAdvisor\\mcpserver\\diagnosis_tool.py"]
    }
  }
}
```

### 配置多个智能体

如果要同时使用多个智能体，可以将所有MCP工具合并到一个配置文件中：

```json
{
  "mcpServers": {
    "OCRTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\HealthRecordsManager\\mcpserver\\ocr_tool.py"]
    },
    "DiagnosisTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\HealthAdvisor\\mcpserver\\diagnosis_tool.py"]
    },
    "ReminderTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\MedicationReminder\\mcpserver\\reminder_tool.py"]
    },
    "DocumentTool": {
      "command": "python",
      "args": ["i:\\A2A\\2\\A2AServer\\backend\\VisitSummaryGenerator\\mcpserver\\document_tool.py"]
    }
  }
}
```

## 启动智能体

### 方法1：独立启动

每个智能体可以独立启动：

```bash
# 启动健康档案管理员
cd HealthRecordsManager
python main.py

# 启动健康顾问
cd HealthAdvisor
python main.py

# 启动用药提醒助手
cd MedicationReminder
python main.py

# 启动就诊摘要生成
cd VisitSummaryGenerator
python main.py
```

### 方法2：MCP工具直接调用

Claude Desktop会根据配置自动启动MCP工具，无需手动启动服务。

## 安全注意事项

1. **API密钥安全**
   - 不要将API密钥提交到版本控制
   - 定期更换API密钥
   - 使用环境变量存储敏感信息

2. **数据隐私**
   - 本地存储用户数据
   - 加密敏感医疗信息
   - 遵循医疗数据保护法规

3. **医疗免责**
   - AI分析仅供参考
   - 不能替代专业医疗诊断
   - 紧急情况请及时就医

## 故障排除

### 常见问题

1. **MCP工具无法启动**
   - 检查Python路径是否正确
   - 确认依赖包已安装
   - 查看Claude Desktop日志

2. **API调用失败**
   - 检查网络连接
   - 验证API密钥配置
   - 查看API使用限制

3. **数据库错误**
   - 检查文件权限
   - 确认SQLite数据库路径
   - 重新初始化数据库

### 日志查看

Claude Desktop的MCP服务器日志位置：
```
C:\Users\YourUsername\AppData\Roaming\Claude\logs\
```
