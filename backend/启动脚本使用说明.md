# A2A智能助手系统 - 启动脚本使用说明

本目录提供了多种方式来一键启动所有智能体服务，支持不同的操作系统和使用场景。

## 📁 文件说明

### 启动脚本

| 文件名 | 平台 | 说明 |
|--------|------|------|
| `start_all_agents_complete.bat` | Windows | Windows批处理脚本，功能完整 |
| `start_all_agents.py` | 跨平台 | Python脚本，功能最丰富，推荐使用 |
| `start_all_agents.sh` | Linux/macOS | Shell脚本，后台运行 |
| `stop_all_agents.sh` | Linux/macOS | 停止所有智能体服务 |

### 原有文件

| 文件名 | 说明 |
|--------|------|
| `start_all_agents.bat` | 原有的Windows启动脚本（仅包含4个智能体） |

## 🚀 使用方法

### Windows 系统

#### 方法1：使用批处理脚本（推荐）
```cmd
# 双击运行或在命令行中执行
start_all_agents_complete.bat
```

#### 方法2：使用Python脚本
```cmd
python start_all_agents.py
```

### Linux/macOS 系统

#### 方法1：使用Shell脚本
```bash
# 添加执行权限
chmod +x start_all_agents.sh
chmod +x stop_all_agents.sh

# 启动所有智能体
./start_all_agents.sh

# 停止所有智能体
./stop_all_agents.sh
```

#### 方法2：使用Python脚本（推荐）
```bash
python3 start_all_agents.py
```

## 🎯 智能体列表

启动脚本将按顺序启动以下6个智能体：

| 序号 | 智能体名称 | 文件夹 | 端口 | 功能描述 |
|------|------------|--------|------|----------|
| 1 | 深度搜索研究 | DeepSearch | 10004 | 深度搜索和医疗资讯查找 |
| 2 | 智能检索助手 | AgentRAG | 10005 | 智能检索和医疗资料查找 |
| 3 | 健康档案管理员 | HealthRecordsManager | 10010 | 健康档案管理 |
| 4 | 健康顾问 | HealthAdvisor | 10011 | 健康咨询和建议 |
| 5 | 用药提醒助手 | MedicationReminder | 10012 | 用药提醒和管理 |
| 6 | 就诊摘要生成 | VisitSummaryGenerator | 8006 | 就诊记录摘要生成 |

## 📋 使用前准备

### 1. 环境要求
- Python 3.7+
- 已安装项目依赖包

### 2. 配置文件
确保每个智能体目录下都有 `.env` 文件，包含必要的API密钥配置：

```bash
# 检查配置文件
ls -la */\.env
```

### 3. 依赖安装
```bash
pip install -r requirements.txt
```

## 🌐 访问地址

启动成功后，可以通过以下地址访问各个智能体：

- 深度搜索研究: http://localhost:10004
- 智能检索助手: http://localhost:10005
- 健康档案管理员: http://localhost:10010
- 健康顾问: http://localhost:10011
- 用药提醒助手: http://localhost:10012
- 就诊摘要生成: http://localhost:8006

### 前端服务

启动智能体后，还需要启动前端API服务：

```bash
cd ../frontend/hostAgentAPI
python api.py
```

前端API地址：http://localhost:13000

## 🛠️ 故障排除

### 常见问题

1. **端口被占用**
   ```bash
   # 查看端口占用情况
   netstat -tulpn | grep :10003
   
   # 停止占用端口的进程
   kill -9 <PID>
   ```

2. **依赖包缺失**
   ```bash
   pip install -r requirements.txt
   ```

3. **环境变量未配置**
   - 检查各智能体目录下的 `.env` 文件
   - 参考 `env_template.txt` 进行配置

4. **权限问题（Linux/macOS）**
   ```bash
   chmod +x *.sh
   ```

### 日志查看

- **Python脚本**：实时显示在控制台
- **Shell脚本**：日志保存在 `logs/` 目录
- **批处理脚本**：每个智能体在独立窗口显示

## 📝 注意事项

1. **启动顺序**：脚本会按照预定顺序启动智能体，每个智能体之间间隔2秒
2. **资源占用**：6个智能体同时运行会占用适中的系统资源
3. **网络端口**：确保所需端口未被其他程序占用
4. **API密钥**：确保所有必要的API密钥都已正确配置
5. **Claude Desktop**：如使用MCP功能，需要配置Claude Desktop
